# FT-04 Floating Price Summary

Sumber PRD: Bagian 5 (BL-01, BL-02), Bagian 6 (FT-04), Bagian 10 (Klausul Estimasi)

## Tujuan
Pengguna dapat memantau rincian biaya layanan utama, biaya tambahan, dan total estimasi secara langsung kapan saja selama mengisi formulir.

## Alur
1. Pengguna memilih layanan, mengubah berat, atau mencentang add-on.
2. Komponen ringkasan langsung memperbarui Biaya Layanan Utama, Biaya Tambahan, dan Estimasi Total.
3. Di layar ponsel (`< 1024px`), bar ringkasan menempel di bawah layar menampilkan Estimasi Total, tombol buka/tutup rincian, dan tombol utama "Kirim ke WhatsApp".
4. Pengguna ponsel dapat mengetuk tombol rincian untuk melihat pecahan Biaya Utama, Biaya Tambahan, Berat Ditagih, serta klausul estimasi awal.
5. Di layar desktop (`>= 1024px`), panel ringkasan tampil tetap (*sticky*) di kolom kanan dengan rincian terbuka penuh.

## Data
- Hasil hitung dari `calculateOrderEstimate` (`src/lib/calculator.ts`) yang membaca `MAIN_SERVICES`, `ADD_ONS`, dan `STORE_INFO.minimumChargeKg` dari `src/config.ts`.
- `ESTIMATE_DISCLAIMER` dari `src/config.ts` (klausul wajib estimasi awal dari PRD).

## Aturan dan rumus
- Rumus PRD (BL-02):
  - `BiayaUtama = Math.round(W_ditagih * TarifLayanan)`
  - `BiayaTambahan = BiayaAntarJemput + BiayaPewangi`
  - `TotalEstimasi = BiayaUtama + BiayaTambahan`
- Urutan hitung:
  1. Validasi dan ubah input berat menjadi `W_aktual`.
  2. Hitung `W_ditagih = max(3.0, W_aktual)`.
  3. Hitung `BiayaUtama`, `BiayaAntarJemput`, dan `BiayaPewangi` sebagai bilangan bulat.
  4. Jumlahkan menjadi `TotalEstimasi`.
- Jika input berat belum valid (`0`, kosong, atau salah format), ringkasan menampilkan `-` pada nominal agar tidak muncul `Rp 0` yang menyesatkan.

## Input dan validasi
- Tidak ada input form langsung pada komponen ini; hanya kontrol tombol buka/tutup rincian (`aria-expanded`) pada tampilan ponsel.

## Tampilan dan teks
- Label total: `Estimasi total` dengan angka besar `text-3xl` (desktop) / `text-2xl` (bar bawah ponsel) memakai `tabular-nums`.
- Baris rincian:
  - `Layanan utama` (nama paket + berat ditagih × tarif/kg) dan subtotalnya.
  - `Layanan tambahan` (total tambahan, beserta rincian Antar-Jemput dan Pewangi Premium jika dipilih; jika tidak ada tampil `Rp 0`).
- Teks wajib klausul estimasi (PRD Bagian 10):
  `Total di atas adalah estimasi awal. Berat pasti akan ditimbang kembali saat pakaian diterima oleh kasir/kurir laundry.`
- Pada layar `360 x 740 px`, tinggi bar bawah tertutup dijaga ringkas (sekitar 84 px, <= 15% tinggi layar) dan tombol aksi utama langsung terlihat tanpa menggulir.
- Tanpa `backdrop-blur` dan tanpa gradasi; latar `bg-white` dengan bayangan melayang `shadow-[0_1px_2px_rgba(0,0,0,0.06),0_8px_24px_rgba(0,0,0,0.08)]`.
