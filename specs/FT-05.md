# FT-05 Form Data Pemesan

Sumber PRD: Bagian 5 (BL-03), Bagian 6 (FT-05), Bagian 8 (AC-03), Bagian 9 (TC-04)

## Tujuan
Pengguna dapat mengisi nama, alamat penjemputan (jika memilih Antar-Jemput), dan catatan khusus untuk disertakan pada pesanan WhatsApp.

## Alur
1. Pengguna mengisi kolom Nama.
2. Jika Antar-Jemput pada FT-03 aktif, kolom Alamat Penjemputan tampil dan wajib diisi. Jika tidak aktif, kolom alamat disembunyikan dan info antar sendiri ke toko ditampilkan.
3. Pengguna dapat mengisi Catatan Khusus bila perlu.
4. Saat tombol kirim ditekan dan ada kolom bermasalah, pesan error tampil di bawah kolom terkait dan fokus berpindah ke kolom error pertama sesuai urutan halaman (`weight` -> `distance` -> `customerName` -> `pickupAddress` -> `memberYears`).

## Data
- `STORE_INFO.pickupRadiusMaxKm` (`5`) dari `src/config.ts`.
- `WHATSAPP_DEFAULTS.selfDropOffText` (`"Antar Sendiri ke Toko"`) dari `src/config.ts`.

## Aturan dan rumus
- Seluruh input teks dihapus spasi di awal dan akhir (`trim()`) sebelum divalidasi dan disusun ke pesan WhatsApp.
- Jika `useDelivery === false`, alamat tidak divalidasi dan pesan WhatsApp otomatis memakai `"Antar Sendiri ke Toko"`.
- Jika `notes.trim() === ""`, pesan WhatsApp otomatis memakai `"-"`.

## Input dan validasi
1. **Nama (`customerName`)**: wajib, error `Isi nama kamu dulu, contoh: Budi Santoso`.
2. **Alamat Penjemputan (`pickupAddress`)**: wajib bila `useDelivery === true`, error `Isi alamat penjemputan lengkap, contoh: Jl. Melati No. 12, Kost Putri`.
3. **Catatan Khusus (`notes`)**: opsional, menerima semua karakter termasuk simbol (`&`, `!`).

## Tampilan dan teks
- Judul bagian: `Data pemesan`
- Label selalu terlihat di atas input, teks input `text-base` (16 px), bingkai `border-neutral-300` untuk kontras tinggi.

## Kasus uji
| ID | Input | Hasil yang diharapkan | Sumber |
| :--- | :--- | :--- | :--- |
| AC-03 / TC-04 | Antar-Jemput aktif, jarak `2` km, Nama `"Budi"`, Alamat `""` | Validasi gagal, muncul error pada kolom Alamat dan fokus pindah ke kolom Alamat | PRD Bagian 8 & 9 |
| FT05-02 | Antar-Jemput tidak aktif, Nama `"Budi"`, Alamat `""` | Validasi lolos tanpa meminta alamat | PRD Bagian 5 |
| FT05-03 | Nama `"   "` (hanya spasi) | Validasi gagal, muncul error pada kolom Nama | Tambahan |
