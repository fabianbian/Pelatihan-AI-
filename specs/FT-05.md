# FT-05 Form Data Pemesan

Sumber PRD: Bagian 5 (BL-03), Bagian 6 (FT-05), Bagian 8 (AC-03), Bagian 9 (TC-04)

## Tujuan
Pengguna dapat mengisi nama, alamat penjemputan (jika memilih Antar-Jemput), dan catatan khusus untuk disertakan pada pesanan WhatsApp.

## Alur
1. Pengguna menggulir ke bagian Data Pemesan.
2. Pengguna mengisi kolom Nama.
3. Jika opsi Antar-Jemput pada FT-03 aktif, kolom Alamat Penjemputan tampil dan wajib diisi. Jika tidak aktif, kolom alamat disembunyikan dan info singkat menampilkan bahwa pakaian diantar sendiri ke toko.
4. Pengguna dapat mengisi Catatan Khusus bila perlu (opsional).
5. Saat tombol kirim ditekan dan ada kolom yang belum valid, pesan error tampil di bawah kolom bermasalah dan fokus otomatis berpindah ke kolom error pertama.

## Data
- `STORE_INFO.pickupRadiusMaxKm` (`5`) dari `src/config.ts` untuk teks bantuan alamat.
- `WHATSAPP_DEFAULTS.selfDropOffText` (`"Antar Sendiri ke Toko"`) dari `src/config.ts`.

## Aturan dan rumus
- Seluruh input teks dihapus spasi di awal dan akhir (`trim()`) sebelum divalidasi dan disusun ke pesan WhatsApp.
- Jika `useDelivery` bernilai `false`, nilai alamat tidak divalidasi dan pada pesan WhatsApp otomatis berisi `"Antar Sendiri ke Toko"`.
- Jika `notes` kosong setelah `trim()`, pesan WhatsApp otomatis memakai `"-"`.

## Input dan validasi
1. **Nama (`customerName`)**
   - Status: Wajib.
   - Atribut: `type="text"`, `name="customerName"`, `autoComplete="name"`.
   - Aturan valid: tidak kosong setelah `trim()`.
   - Pesan error: `Isi nama kamu dulu, contoh: Budi Santoso`
2. **Alamat Penjemputan (`pickupAddress`)**
   - Status: Kondisional (wajib hanya saat `useDelivery === true`).
   - Atribut: `name="pickupAddress"`, `autoComplete="street-address"`.
   - Aturan valid: tidak kosong setelah `trim()` saat `useDelivery === true`.
   - Pesan error: `Isi alamat penjemputan lengkap, contoh: Jl. Melati No. 12, Kost Putri`
3. **Catatan Khusus (`notes`)**
   - Status: Opsional.
   - Atribut: `name="notes"`.
   - Aturan valid: menerima semua karakter termasuk simbol (`&`, `!`, koma, tanda hubung).

## Tampilan dan teks
- Judul bagian: `Data pemesan`
- Setiap kolom memiliki label yang selalu terlihat di atas input dan ukuran teks input `text-base` (16 px).
- Kolom Nama: label `Nama`, placeholder `Contoh: Budi Santoso`.
- Kolom Alamat (saat Antar-Jemput aktif): label `Alamat penjemputan`, bantuan `Dalam radius maks 5 km dari toko.`, placeholder `Contoh: Jl. Melati No. 12, Kost Putri`.
- Info saat Antar-Jemput tidak aktif: `Antar sendiri ke toko. Aktifkan Antar-Jemput jika perlu dijemput.`
- Kolom Catatan: label `Catatan khusus (opsional)`, placeholder `Contoh: Pisahkan baju putih dan berwarna`.
