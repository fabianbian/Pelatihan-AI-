# FT-02 Input Berat & Notifikasi Min. Charge

Sumber PRD: Bagian 5 (BL-01), Bagian 6 (FT-02), Bagian 8 (AC-01), Bagian 9 (TC-01, TC-03), Bagian 11 (`store_info.minimum_charge_kg`)

## Tujuan
Pengguna dapat memasukkan estimasi berat cucian dalam kilogram dan langsung melihat pemberitahuan apabila aturan minimum charge 3 kg berlaku.

## Alur
1. Pengguna melihat kolom estimasi berat dengan nilai awal `3` kg.
2. Pengguna mengetik angka berat (memakai koma atau titik) atau menekan tombol `-0,5` dan `+0,5`.
3. Sistem menghitung berat ditagih (`max(3.0, beratAktual)`).
4. Jika berat aktual valid (`> 0`) dan kurang dari `3 kg`, notifikasi peringatan amber otomatis tampil menjelaskan bahwa berat ditagih menjadi `3 kg`.
5. Jika berat `>= 3 kg`, notifikasi minimum charge tidak tampil.
6. Jika kolom kosong, `0`, negatif, atau bukan angka valid, estimasi ditahan dan pesan error tampil saat tombol kirim ditekan.

## Data
- `STORE_INFO.minimumChargeKg` (`3.0`)
- `WEIGHT_RULES.defaultKg` (`3`)
- `WEIGHT_RULES.minKg` (`0.1`)
- `WEIGHT_RULES.maxKg` (`100`)
- `WEIGHT_RULES.stepKg` (`0.1`)
- `WEIGHT_RULES.quickStepKg` (`0.5`)

## Aturan dan rumus
- Rumus PRD (BL-01):
  - `W_ditagih = max(3.0, W_aktual)`
- Keputusan turunan:
  - Satuan: kilogram (`kg`).
  - Format input: menerima koma (`,`) dan titik (`.`) sebagai pemisah desimal; spasi di awal/akhir dihapus sebelum dibaca.
  - Rentang valid: `0,1 <= W_aktual <= 100`.
  - Penyesuaian tombol cepat: `-0,5` dan `+0,5`, dibulatkan ke 1 angka di belakang koma (`Math.round(val * 10) / 10`) dan dijaga dalam rentang `0,1` sampai `100`.
  - Tampilan desimal: koma sebagai pemisah, tanpa nol di belakang (contoh: `4,5` dan `3`).
  - Notifikasi minimum charge aktif saat `W_aktual` valid (`>= 0,1`) dan `W_aktual < 3`.

## Input dan validasi
- Kolom `weight` (wajib):
  - Atribut: `type="text"`, `inputMode="decimal"`, `name="weight"`, `autoComplete="off"`.
  - Valid jika dapat diubah menjadi angka berhingga dengan nilai `>= 0,1` dan `<= 100`.
  - Error jika kosong atau `<= 0`: `Masukkan berat cucian minimal 0,1 kg, contoh: 2,5`
  - Error jika tidak berupa angka: `Gunakan angka untuk berat cucian, contoh: 3,5`
  - Error jika `> 100`: `Masukkan berat maksimal 100 kg, contoh: 12`

## Tampilan dan teks
- Judul bagian: `Estimasi berat cucian`
- Label kolom selalu terlihat: `Berat cucian (kg)` dengan teks bantuan `Minimal 0,1 kg, ketik koma atau titik.`
- Tombol pengatur cepat `-0,5` dan `+0,5` dengan area sentuh minimal `44 x 44 px`.
- Notifikasi minimum charge (tampil saat `0,1 <= W_aktual < 3`): kotak `bg-amber-50 text-amber-800` dengan ikon info dan teks:
  `Ketentuan minimum 3 kg berlaku. Berat ditagih menjadi 3 kg.`
- Pesan error tampil tepat di bawah kolom dengan teks merah dan ikon peringatan.
