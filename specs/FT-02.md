# FT-02 Input Berat Aktual Desimal

Sumber PRD: Bagian 5 (BL-01), Bagian 6 (FT-02), Bagian 9 (TC-03), dan permintaan terbaru pengguna (hapus minimum 3 kg dan jangan dibulatkan)

## Tujuan
Pengguna dapat memasukkan estimasi berat cucian dalam angka desimal penuh tanpa pembulatan dan biaya langsung dihitung persis sesuai berat tersebut.

## Alur
1. Pengguna melihat kolom estimasi berat dengan nilai awal `1` kg.
2. Pengguna mengetik angka berat desimal bebas memakai koma atau titik (misalnya `2,43` atau `0,5`), atau menekan tombol cepat `-0,5` dan `+0,5`.
3. Sistem mempertahankan angka desimal persis tanpa membulatkan berat dan tanpa menaikkan ke minimum 3 kg.
4. Berat tersebut langsung menjadi dasar perkalian biaya layanan utama dan Pewangi Premium.
5. Jika kolom kosong, `< 0,1`, lebih dari `100`, atau bukan angka valid, estimasi ditahan dan pesan error tampil saat tombol kirim ditekan.

## Data
- `WEIGHT_RULES.defaultKg` (`1`)
- `WEIGHT_RULES.minKg` (`0.1`)
- `WEIGHT_RULES.maxKg` (`100`)
- `WEIGHT_RULES.quickStepKg` (`0.5`)

## Aturan dan rumus
- Rumus iterasi terbaru (menimpa batas minimum 3 kg):
  - `W_ditagih = W_aktual`
- Keputusan turunan:
  - Satuan: kilogram (`kg`).
  - Format input: menerima koma (`,`) dan titik (`.`) sebagai pemisah desimal; spasi awal/akhir dihapus sebelum dibaca.
  - Tanpa pembulatan pada nilai berat: angka seperti `2,43` atau `4,125` dipertahankan utuh (hanya nol tak bermakna di belakang seperti `2,50` diringkas menjadi `2,5`).
  - Rentang valid: `0,1 <= W_aktual <= 100`.
  - Penyesuaian tombol cepat: menambah/mengurangi `0,5` kg tanpa merusak presisi desimal saat ini dan dijaga dalam rentang `0,1` sampai `100`.

## Input dan validasi
- Kolom `weight` (wajib):
  - Atribut: `type="text"`, `inputMode="decimal"`, `name="weight"`, `autoComplete="off"`.
  - Error jika kosong atau `< 0,1`: `Masukkan berat cucian minimal 0,1 kg, contoh: 2,43`
  - Error jika tidak berupa angka: `Gunakan angka untuk berat cucian, contoh: 2,43`
  - Error jika `> 100`: `Masukkan berat maksimal 100 kg, contoh: 12,5`

## Tampilan dan teks
- Judul bagian: `Estimasi berat cucian`
- Label kolom selalu terlihat: `Berat cucian (kg)` dengan teks bantuan `Minimal 0,1 kg, dihitung sesuai berat tanpa pembulatan.`
- Tombol pengatur cepat `-0,5` dan `+0,5` dengan area sentuh minimal `44 x 44 px`.
- Tidak menampilkan kotak peringatan minimum charge 3 kg.
